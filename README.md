# Frozen Hub

GitHub Pages deployment package with the integrated **Frozen Hub Inventory** module.

Upload all extracted files and the `icons` folder to the repository root. Replace the existing files, commit the changes, wait for GitHub Pages deployment, then refresh the website with `Ctrl + F5`.

Build v21 fixes Full Backup restore for Cash & Carry. Cash & Carry data is included in the Full Backup and does not require a separate restore.

Build v22 restores the Sales & Production submenu and adds the month-wise Raw Potato Purchase / Consumption & Rates report with Print and Excel export.

Build v23 adds the Sales & Production dropdown to the active ERP top navigation on desktop and mobile, with report-level user permissions.

Build v24 limits the Potato Purchase & Rates report to Raw Potato materials only and excludes finished items such as Potato Skin.

Build v25 groups the Potato report by raw material first, then shows month-wise quantity, amount and rate with a separate weighted-average subtotal for each item.

Build v26 changes the Potato report explanation to English.

Build v27 adds an All Months / specific month filter and recalculates each item subtotal plus the All Items Total and weighted-average rate.

Build v28 adds a professionally formatted Excel export with item sections, formulas, number formats, frozen headers and landscape print settings.
